# MOMENT — White Editorial Watch Store

A fresh visual direction for MOMENT, rebuilt as a white editorial storefront rather than a reskin of the previous VÉLOR layout.

## Visual direction
- Pure white page background throughout.
- Navy typography and restrained antique-gold accents.
- Asymmetric editorial hero with a wristwatch campaign photograph.
- Consistent square product-image frames (1:1), white image canvases and object-fit containment.
- English navigation, headlines, model names and interface copy.
- Short Arabic descriptions inside individual watch detail views only.
- Responsive desktop and mobile layouts.

## Storefront interactions
- Product filtering and price sorting.
- Product detail modal.
- Shopping bag drawer with quantity controls and subtotal.
- Demo order form with optional WhatsApp handoff.

## Run locally
Open index.html in a browser or serve the folder with a static web server. Internet access is required for remote images and Google Fonts.

## Demo content and image notes
Watch model names, EGP prices and Arabic descriptions are placeholders. Product photographs are remotely hosted reference imagery from watch retailers and editorial portfolios, used to establish a consistent navy/gold visual direction. Confirm image usage rights and replace with approved brand-owned photography before commercial launch. Add the actual WhatsApp number in app.js before enabling order handoff.
