# MOMENT — Watch Store Concept

A responsive storefront concept for a modern watch brand, built by FIKRA.

## Included
- MOMENT brand identity with a clean white, navy, and gold direction.
- English navigation, product names, sections, cart, and checkout UI.
- Short Arabic product descriptions inside product details.
- White product image canvases and consistent image framing.
- Featured Models section, product collection filters, search, and sorting.
- Responsive product grid and mobile navigation.
- Cart drawer, product detail modal, demo checkout, and WhatsApp handoff placeholder.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server. An internet connection is required for hosted images and Google Fonts.

## Before launch
- Replace demo watch images with approved product photography.
- Confirm real product names, specifications, prices, stock, and policies.
- Add the brand WhatsApp number in `app.js` (`WHATSAPP_NUMBER`).
- Connect checkout to the actual order process; the current checkout is a front-end demo only.
- Check trademark, domain, and social handle availability before commercial use.
